# Visual direction

The title screen introduces the forest before asking the player to create a room. A painted landscape, a large serif wordmark and one narrow entry form replace the previous dashboard composition. In a room, the canvas takes priority and the roster sits beside it.

The original title illustration was generated for this project. Gameplay characters and scenery use Canvas drawing code. `public/art/trailhead.png` is the retained title asset.

References: the immersive, experience-first approach in Awwwards' Gallery of the Gamer and games/entertainment collection. No reference assets were copied.

Review criteria: readable title and room controls; distinct title and active-game states; no title artwork over gameplay; keyboard focus; reduced-motion styling; phone-sized layout. Builds, source checks and multiplayer tests passed. Browser screenshot review was unavailable during this update and remains a verification limit.
